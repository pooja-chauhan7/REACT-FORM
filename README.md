
# React Information Form

## Project Overview
The React Information Form is a responsive web application
that demonstrates different form controls, form validation,
and browser-based data storage.

## Features
- Responsive form for desktop, tablet, and mobile
- Text inputs, textarea, number input, and date picker
- Dropdown and multi-select options
- Radio buttons, checkboxes, and toggle switches
- Required-field validation
- Form submission and reset functionality
- Save records in browser localStorage
- Automatically load saved records after refresh
- Edit and delete saved records
- Confirmation popups for reset and delete

## Technologies Used
- React
- JavaScript
- HTML5
- CSS3
- Browser localStorage
- Vite

## Prerequisites
- Node.js and npm installed
- A code editor such as Visual Studio Code

## Installation

1. Download or clone the project.
2. Open the project folder in a terminal.
3. Install dependencies:

   npm install

## Run the Project

   npm run dev

Open the local URL shown in the terminal, usually:
http://localhost:5173

## Data Storage
Submitted records are stored in the browser's localStorage.
Saved records remain available after refreshing the page
in the same browser, unless the stored data is cleared.
